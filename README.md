# ImproofFund - Web3 Funding Platform

A modern Next.js frontend for interacting with the ImproofFund smart contract built with Foundry.

## 🌐 Live Demo

**Check out the live demo: [frontend-fund-me-foundry.vercel.app](https://frontend-fund-me-foundry.vercel.app/)**

## 🚀 Features

- Connect MetaMask or other Ethereum wallets
- Beautiful UI with light/dark mode toggle
- View contract information (balance, minimum funding amount)
- Fund the contract with ETH
- Withdraw funds (contract owner only)

## 🛠️ Technologies

- Next.js 15, TypeScript, Tailwind CSS
- wagmi, viem, React Query, next-themes

## 🔧 Getting Started

### Prerequisites

- Node.js (v18+), npm or yarn
- A deployed ImproofFund contract on Sepolia testnet

### Setup

1. Clone this repository:
```bash
git clone https://github.com/yuriimproof/frontend-fund-me-foundry.git
cd frontend-fund-me-foundry
```

2. Install dependencies and start the dev server:
```bash
npm install
npm run dev
```

## 🚢 Deployment

This project is deployed on Vercel at [frontend-fund-me-foundry.vercel.app](https://frontend-fund-me-foundry.vercel.app/).
